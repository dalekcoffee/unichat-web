# UniChat

Live chat from Twitch, TikTok, Kick, Velora, Blaze and Nimo TV, merged into one read-only page. It runs in your browser, with nothing to install and no logins.

**Open it: <https://chat.dalek.coffee>**

## What it does
- Shows every platform's chat, emotes and alerts (subs, gifts, raids, tips) in one feed.
- Optional sounds, popups and text-to-speech for alerts.
- Includes an overlay page for OBS.
- Keeps your settings in your browser, or in a link you can bookmark.

## TikTok API key
TikTok chat needs a free Euler Stream API key:
1. Create a free account at <https://www.eulerstream.com/>.
2. Copy your API key from the Euler dashboard.
3. In UniChat, paste it into **Settings → TikTok** and click **Save**.

The key is only saved in your browser. Leave *Include my TikTok (Euler) key in these links* unticked for any link you share.
